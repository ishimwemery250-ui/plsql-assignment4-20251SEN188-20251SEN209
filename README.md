Assignment IV - Student registration and grading system

Sangwa Dejoie 20251SEN209 Ishimwe Emery 20251SEN188 Class C We have three tables. Students stores names and emails. Courses stores information about the courses. Enrollments shows which student takes which course and the grade they got.

Our system can add students, enroll them in a course, give them grades, show students in a course, and calculate average marks. It can also give bonus marks to several students at once.

We also made some rules. Two students cannot use the same email. One student cannot register for the same course twice. Grades must be from 0 to 100. A course has a limited number of places.

The folders

00_schema has the tables and example data. 01_procedures has the procedures we made. 02_functions has functions that return information. 03_tests has tests for normal cases and for errors. docs has our explanation of the code. 00_schema_screenshots has screenshots of creating tables and inserting example data. 01_procedure_screenshots has screenshots showing the results of our seven procedures. 02_functions_screenshots has screenshots showing the results of our three functions. 03_tests has screenshots of error tests and checking the database structure.
